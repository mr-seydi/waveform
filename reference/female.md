# Female thorax obliquity curves

Thorax obliquity (upward/downward motion) curves for 71 female
participants during walking, observed on a common grid of 101 points.
Each column is a participant and each row is an evaluation point.

## Usage

``` r
data(female)
```

## Format

A numeric matrix with 101 rows (evaluation points) and 71 columns
(participants). Column names identify participants.

## Source

Van Criekinge T, Saeys W, Truijen S, Vereeck L, Sloot LH, Hallemans A. A
full-body motion capture gait dataset of 138 able-bodied adults across
the life span and 50 stroke survivors. *Scientific Data*. 2023;10:852.
<https://doi.org/10.1038/s41597-023-02767-y>. The data are publicly
available from the [Figshare
collection](https://doi.org/10.6084/m9.figshare.c.6503791.v1).
