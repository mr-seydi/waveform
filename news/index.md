# Changelog

## waveform 1.1.0

- Added male and female thorax obliquity datasets with source
  documentation.
- Added a getting-started vignette with examples based on the observed
  data.
- [`smooth_gaussian_curves()`](https://mr-seydi.github.io/waveform/reference/smooth_gaussian_curves.md)
  and
  [`gaussian_curves_generator()`](https://mr-seydi.github.io/waveform/reference/gaussian_curves_generator.md)
  now accept pointwise mean and standard deviation vectors, as well as
  scalar values.
- Added a package hex sticker and a pkgdown website configuration.
